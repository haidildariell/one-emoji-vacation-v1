# One Emoji, One Dream Vacation — 🏝️

One emoji, one dream vacation: a desert island. A remote island escape —
the most iconic dream-vacation postcard, specific and instantly readable
across cultures and screens.

The entry program (`main.py`) writes exactly that one emoji to
`/output/entry.txt`, with no trailing newline and no extra words.
